# PlantPass workspace

This folder holds the two PlantPass repositories side by side. It is not a
repository itself. This file is generated by `make workspace` in
`plantpass-backend`; edit `plantpass-backend/docs/workspace-CLAUDE.md`, not
this copy.

- `plantpass-backend/` — Lambdas, Terraform, product docs, and the agent
  skills for both repos.
- `plantpass-frontend/` — the React app. Its own rules are in
  `plantpass-frontend/AGENTS.md`; read them before touching it.

Git commands need a repo: use `git -C plantpass-backend ...` or
`git -C plantpass-frontend ...`.
